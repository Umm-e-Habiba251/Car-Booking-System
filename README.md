# Car Booking System 🚖

The Car Booking System is a console-based Java project that manages ride bookings using Data Structures and SQL database connectivity. It allows users to book rides, serve customers, search records, undo rides, and manage ride details efficiently using Linked List, Stack, and Heap concepts.

## Features
- Book Ride
- Serve Ride
- Undo Ride
- Search Ride
- Show All Rides
- Priority Ride Handling

## Technologies Used
- Java
- JDBC
- SQL Server
- Data Structures
